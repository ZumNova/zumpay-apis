# Zumpay Agent APIs

Microservicios de Zumpay para agentes de IA en Arc.

Este repo queda separado de la dApp principal `zumpay.com.ar`. Aca viven las APIs pagas, OpenAPI y servicios x402/Circle:

- `api.zumpay`: datos financieros y liquidez de pools.
- `risk.zumpay`: analisis de riesgo Anti-Rugpull.
- `snip.zumpay`: feed de pares y pools nuevos.

Cada carpeta es un proyecto Vercel independiente.
